# เครือญาติ

## การแจ้งเตือน

กระดิ่งแจ้งเตือนอยู่ในหน้าแผนผัง ข่าวสาร และบัญชี แสดงจำนวนรายการที่ยังไม่อ่าน เปิดดูรายการ กดอ่านทั้งหมด หรือกดรายการเพื่อไปยังข่าว/ความคิดเห็นนั้นได้ อัปเดตทุก 30 วินาทีเมื่อหน้าเว็บเปิดอยู่และกลับมาดูแท็บ ไม่ใช่การแจ้งเตือนแบบ push เมื่อปิดเว็บ และไม่มีการส่งอีเมล

แจ้งเตือนข่าวสารใหม่เฉพาะสมาชิกที่มีสิทธิ์ดู ณ เวลาที่โพสต์ ความคิดเห็นใหม่แจ้งผู้โพสต์และผู้ที่เคยร่วมแสดงความคิดเห็นโดยตรวจสิทธิ์ผู้ชมปัจจุบัน ปฏิกิริยาแจ้งเจ้าของโพสต์ ไม่แจ้งกิจกรรมของตนเอง การแก้ไขโพสต์/ความคิดเห็นไม่ส่งซ้ำ การเปลี่ยนปฏิกิริยาปรับแจ้งเตือนเดิมและการยกเลิกปฏิกิริยาจะเอารายการนั้นออก

บันทึกในตาราง notifications ภายใน SQLite พร้อมสถานะอ่านของแต่ละคน ผู้ใช้แก้สถานะอ่านของคนอื่นไม่ได้ ตรวจสิทธิ์ผู้ชมซ้ำตอนโหลดแจ้งเตือนและเปิดลิงก์ หากผู้โพสต์เปลี่ยนระดับผู้ชม รายการที่ไม่มีสิทธิ์แล้วจะไม่แสดง ลบโพสต์/ความคิดเห็นจะล้างการแจ้งเตือนที่เกี่ยวข้องตามด้วย เริ่มแจ้งกิจกรรมใหม่หลังติดตั้ง ไม่มีการสร้างแจ้งเตือนย้อนหลังสำหรับข่าวเก่า

## ข่าวสารครอบครัว

เมนูข่าวสารเปิดที่ `news.php` เป็นฟีดเดียว ไม่แบ่งหมวด สมาชิกทุกคนที่เข้าสู่ระบบอ่านและโพสต์ได้ โพสต์ข้อความหรือไฟล์อย่างเดียวได้ และแก้ไข/ลบได้เฉพาะผู้โพสต์เดิม ไม่มีการเปลี่ยนข้อมูลวันเกิด/วันเสียชีวิตในทะเบียนจากโพสต์โดยอัตโนมัติ

แต่ละโพสต์กำหนดผู้ชมได้เป็น “ทุกคนที่ใช้งานเว็บ” (สมาชิกที่เข้าสู่ระบบ) หรือ “เฉพาะเครือญาติตามระดับที่เลือก” เลือกได้ถึง 10 ระดับ และเลือกเฉพาะบางระดับ เช่น 1 กับ 3 ได้ ระดับนับจำนวนเส้นเชื่อมที่สั้นที่สุดจากเลขบัตรบัญชีผู้โพสต์: พ่อแม่ ลูก คู่สมรส = 1 เส้น; พี่น้อง ปู่ย่า ตายาย หลาน = 2 เส้น; นับต่อไปตามความสัมพันธ์จริง รวมข้อมูลข้ามบัญชีที่เลขบัตรตรงกันเป็นบุคคลเดียว ต้องมีตัวผู้โพสต์ในทะเบียนก่อนเลือกแบบจำกัดระดับ ผู้โพสต์เห็นข่าวสารของตนเองเสมอ ผู้ที่ไม่เกี่ยวข้องไม่เห็นโพสต์แบบจำกัดระดับ

ตรวจผู้ชมฝั่งเซิร์ฟเวอร์ทั้งฟีด การเปิด/ดาวน์โหลด/เล่นไฟล์แนบแบบ byte range ความคิดเห็น และปฏิกิริยา การเปลี่ยนผู้ชมมีผลต่อสิทธิ์ในคำขอถัดไปโดยคำนวณจากบัญชีและเครือญาติปัจจุบัน โพสต์เก่าก่อนเพิ่มฟีเจอร์นี้คงเป็นทุกคนในเว็บ ผู้โพสต์แก้ไขตัวเลือกผู้ชมได้

ผู้ชมโพสต์ส่งปฏิกิริยาได้หนึ่งชนิดต่อคน (ถูกใจ รัก ยินดีด้วย ส่งกำลังใจ) กดซ้ำเพื่อยกเลิกหรือเลือกแบบอื่นแทนได้ แสดงความคิดเห็นได้ไม่เกิน 2,000 ตัวอักษรต่อรายการ แก้ไข/ลบได้เฉพาะผู้เขียนความคิดเห็นเอง โหลดความคิดเห็นครั้งละ 20 รายการพร้อมปุ่มดูก่อนหน้า ตาราง news_comments/news_reactions ถูกล้างตามเมื่อโพสต์ถูกลบ

รองรับรูป JPG/PNG/WebP, GIF เคลื่อนไหว, HEIC/HEIF (แปลงเป็น JPG ในเบราว์เซอร์), วิดีโอ MP4/WebM/MOV, เสียง MP3/M4A/WAV/OGG, PDF, TXT, ZIP, DOCX/XLSX/PPTX สูงสุด 8 ไฟล์ต่อโพสต์ วิดีโอไม่เกิน 100 MB ต่อไฟล์ ไฟล์อื่นไม่เกิน 25 MB ข้อความไม่เกิน 10,000 ตัวอักษร รูปเปิดขนาดใหญ่ได้ วิดีโอ/เสียงใช้ตัวเล่นของเบราว์เซอร์ PDF เปิดอ่านในแท็บใหม่ เอกสารอื่นดาวน์โหลด ไฟล์ที่เบราว์เซอร์เล่นไม่ได้ยังดาวน์โหลดได้

อัปโหลดไฟล์เป็นส่วนละ 1 MB เพื่อใช้กับข้อจำกัด PHP เดิม ตรวจชนิดจากเนื้อหาไฟล์ฝั่งเซิร์ฟเวอร์ และตรวจเจ้าของไฟล์ร่างกับ CSRF ก่อนบันทึก ฟีดโหลดครั้งละ 20 โพสต์ ไฟล์วิดีโอรองรับ byte ranges เพื่อเลื่อนตำแหน่งเล่นได้

ตาราง news_posts/news_files สร้างอัตโนมัติใน SQLite ไฟล์แนบจัดเก็บใน `storage/news_files` และส่งผ่าน `news-file.php` ที่ต้องเข้าสู่ระบบ ไฟล์ร่างที่ยังไม่โพสต์จะถูกล้างหลัง 24 ชั่วโมงเมื่อมีการเริ่มอัปโหลดใหม่ การสำรองข่าวสารต้องสำรองทั้ง `storage/family.sqlite` และ `storage/news_files` ในช่วงหยุดเขียนข้อมูล ไฟล์ที่เอาออกจากโพสต์และไฟล์ของโพสต์ที่ลบจะถูกลบจากพื้นที่จัดเก็บด้วย

ทดสอบ API: `node tests/news.test.cjs` ใช้ฐานข้อมูลชั่วคราว ตรวจสิทธิ์ โพสต์ แก้ไข ลบ รูป/GIF/PDF วิดีโอแบ่งส่วน byte ranges ชนิดไฟล์และการล้างไฟล์ ทดสอบหน้าจอจริง: `node tests/news-browser.test.cjs` ใช้ Edge headless (กำหนด EDGE_PATH ได้) เพื่อโพสต์และแก้ไขพร้อมภาพ/GIF/PDF/WebM ที่เล่นได้จริง

เว็บแอปภาษาไทย PHP 8.1+ / PDO SQLite ไม่ต้องติดตั้งแพ็กเกจ เปิดผ่าน Laragon ที่ `http://family.test` หรือ `http://localhost/family/` ตามการตั้งค่าเครื่อง

เพิ่ม/แก้ไข/ลบบุคคล ค้นหาชื่อ ชื่อเล่น หรือเลขบัตร เชื่อมบิดา มารดา คู่สมรส แสดงสายสัมพันธ์ ลากและซูมแผนผังได้ ข้อมูลตัวอย่างในปุ่มทดลองอยู่ในหน่วยความจำและไม่เขียนลงฐานข้อมูล

เพิ่มหรือเปลี่ยนรูปได้ในฟอร์มบุคคล รองรับ JPG, PNG, WebP, HEIC/HEIF ต้นฉบับไม่เกิน 25 MB แปลงเป็น JPEG และย่อด้านยาวไม่เกิน 1,024 พิกเซลโดยรักษาสัดส่วน ไม่ขยายภาพเล็ก รูปที่ส่งไปบันทึกมีขนาดไม่เกิน 2 MB มีพรีวิวก่อนบันทึกและตัวเลือกลบรูป รูปแสดงบนการ์ด ทะเบียน และ MEMBER PROFILE จัดเก็บในตาราง person_photos ภายใน SQLite จึงสำรองไปพร้อมฐานข้อมูล photo.php ตรวจการเข้าสู่ระบบและสิทธิ์ดูเครือญาติก่อนส่งรูป ผู้ป้อนเดิมหรือผู้ที่เลขบัตรบัญชีตรงกับบุคคลนั้นสามารถแก้ไขรูปได้

แปลง HEIC ด้วย heic2any 0.0.4 ที่เก็บไว้ใน assets/vendor พร้อมใบอนุญาต MIT โดยโหลดเมื่อจำเป็นเท่านั้น การแปลงและย่อทำในเบราว์เซอร์ ไม่ส่งรูปไปบริการแปลงภายนอก ไม่เก็บไฟล์ต้นฉบับหรือ metadata ภาพเคลื่อนไหว/ภาพชุดใช้ภาพแรก ไฟล์ที่ตัวแปลงอ่านไม่ได้จะแสดงข้อผิดพลาดและไม่ส่งไฟล์ต้นฉบับไปเซิร์ฟเวอร์

ทดสอบ HEIC จริงและการย่อรูปด้วย Edge: `node tests/photo-browser.test.cjs` (กำหนด EDGE_PATH ได้) ใช้เว็บเซิร์ฟเวอร์และโปรไฟล์เบราว์เซอร์ชั่วคราว ทดสอบการส่งฟอร์มระหว่างรอแปลงด้วย

ใช้ id ภายในเป็น Primary Key และ national_id เป็น UNIQUE ยอมรับเลข 13 หลัก (ยังไม่ตรวจ checksum) รองรับพ่อและแม่อย่างละหนึ่งคน และคู่สมรสปัจจุบันหนึ่งคน ไม่รองรับประวัติสมรสหรือบุตรบุญธรรมแยกประเภท

ฐานข้อมูลสร้างอัตโนมัติที่ `storage/family.sqlite` ต้องเปิด extension `pdo_sqlite` และให้ PHP เขียนโฟลเดอร์ storage ได้ สำรองข้อมูลโดยหยุดการเขียนชั่วคราวแล้วคัดลอกฐานข้อมูล

ผู้ใช้งานลงทะเบียนเองได้ที่ `auth.php?mode=register` ด้วยชื่อ อีเมล เลขบัตร และรหัสผ่าน แล้วเข้าสู่ระบบที่ `auth.php` ข้อมูลเครือญาติที่เชื่อมกันอ่านข้ามบัญชีได้ การแก้ไข ลบ และกำหนดความสัมพันธ์ตรวจเจ้าของผ่าน API เลขบัตรไม่ซ้ำภายในบัญชีเดียวกัน รหัสผ่านจัดเก็บด้วย password_hash มี CSRF token และจำกัดการล็อกอินผิด 5 ครั้งต่ออีเมลใน 15 นาที ยังไม่มีการยืนยันอีเมลหรือรีเซ็ตรหัสผ่าน

บัญชีใหม่ต้องระบุเลขบัตรประชาชน 13 หลักและไม่ซ้ำกับบัญชีอื่น บัญชีเดิมจะถูกพาไป `account.php` เพื่อกรอกเลขบัตรพร้อมยืนยันรหัสผ่าน ข้อมูลนี้เป็นค่าที่ผู้ใช้ระบุเอง ยังไม่มีการพิสูจน์ตัวตนหรือเช็ก checksum การเปลี่ยนเลขบัตรบัญชีไม่เปลี่ยนเลขบัตรบุคคลในทะเบียนโดยอัตโนมัติ

เพิ่มบุคคลของตนเองในทะเบียนด้วยเลขบัตรเดียวกับบัญชี แล้วระบุพ่อและแม่ แผนผังเริ่มต้นจะแสดงจากพ่อแม่ลงมาถึงผู้ใช้ พี่น้อง คู่สมรสและลูก ปุ่ม “ดูเครือญาติที่เชื่อมโยงทั้งหมด” ขยายทั้งองค์ประกอบที่มีเส้นเชื่อมกัน รวมบรรพบุรุษและญาติสาขาอื่น คลิกบุคคลแล้วเลือก “ดูเครือญาติของคนนี้” เพื่อเปลี่ยนจุดเริ่มต้นได้ หากยังไม่มีข้อมูลพ่อแม่จะแสดงจากตัวบุคคลก่อน

เครือญาติข้ามบัญชีแสดงอัตโนมัติหลังเข้าสู่ระบบ ไม่ต้องส่งคำขอหรืออนุมัติ ระบบตามเลขบัตรเดียวกันและความสัมพันธ์พ่อแม่ คู่สมรส บุตร ต่อไปได้ทุกสาขาและหลายบัญชี โดยไม่ดึงรายการอื่นที่ไม่เชื่อมโยงกันของบัญชีญาติมาแสดง ข้อมูลจากหลายบัญชีที่เลขบัตรตรงกันถูกรวมเป็นบุคคลเดียวในแผนผัง แต่ฐานข้อมูลต้นฉบับยังแยกกัน

เจ้าของแก้ไขและลบได้เฉพาะรายการที่ตนป้อน ข้อมูลของคนอื่นอ่านได้เท่านั้น การแก้ไขสำเนาของตนไม่เขียนทับสำเนาของอีกบัญชี ตาราง family_links เดิมเก็บไว้เพื่อรักษาข้อมูลเดิม แต่ไม่มีผลต่อสิทธิ์แสดงแผนผังอีกต่อไป

ระบบเพิ่มตาราง users และ login_attempts ใน family.sqlite และเพิ่ม owner_id ใน persons อัตโนมัติ ข้อมูลเดิมที่ไม่มีเจ้าของจะเก็บไว้เป็น owner_id=NULL และดูได้เมื่อเชื่อมโยงกับครอบครัวของผู้ใช้ แต่ยังแก้ไขไม่ได้ หากต้องการแก้ไขข้อมูลเดิมต้องให้ผู้ดูแลกำหนดเจ้าของในฐานข้อมูลอย่างเหมาะสม

ยังไม่มีประวัติการแก้ไขหรือการเข้ารหัสฐานข้อมูล เลขบัตรเต็มจัดเก็บในฐานข้อมูลและส่งให้เบราว์เซอร์ของผู้ใช้ที่ดูเครือญาติเชื่อมโยงได้ แต่แสดงแบบปกปิดบนหน้าจอ ใช้ HTTPS หากเปิดใช้งานผ่านเครือข่าย

Apache ป้องกันการเข้าถึง storage ด้วย .htaccess หากใช้เว็บเซิร์ฟเวอร์อื่นต้องตั้งค่า deny โฟลเดอร์ storage ด้วย ไม่ควรนำขึ้นเซิร์ฟเวอร์สาธารณะตามการตั้งค่าเริ่มต้น

ฟอนต์โหลดจาก Google Fonts เมื่อออนไลน์ และใช้ sans-serif เมื่อออฟไลน์ โดยไม่มีการส่งข้อมูลทะเบียนไปบริการภายนอก

ตรวจ syntax: `php -l index.php` และ `php -l api.php`; `node --check app.js`
